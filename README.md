# Дайвинчик-бот для Telegram

Готовый MVP на Python 3.11 + aiogram 3 + SQLite. В интерфейсе короткие кнопки: анкета, поиск, лайки, настройки, язык. Есть админ-панель с поиском по ID анкеты/Telegram ID, удалением анкет, баном пользователей и управлением репутацией.

## Важно про токен
Токен был опубликован в переписке. Немедленно отзови его через BotFather командой `/revoke`, создай новый и запиши его только в `.env`. Реальный токен в проект не включён.

## Запуск
```bash
cd dating_bot
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
cp .env.example .env
# впиши новый токен в .env
python bot.py
```

Админ по умолчанию: `1398491942`.

## Что реализовано
- выбор русского/английского языка при первом запуске;
- принятие лицензионного соглашения;
- создание и редактирование анкеты: имя, возраст, город, о себе, интересы, фото;
- просмотр анкет и действия «нравится», «пропустить», «пожаловаться»;
- взаимные симпатии и уведомления;
- меню настроек и скрытие/удаление анкеты;
- репутация пользователей;
- админка: статистика, поиск по ID анкеты и Telegram ID, просмотр анкеты, удаление, бан/разбан, изменение репутации;
- SQLite без внешней базы данных.

Для продакшена добавь webhook/Redis, резервные копии SQLite, модерацию фото и хранение медиа в S3. Не храни и не логируй токены.
