# Дайвинчик 2.0 — безопасные знакомства «от входа до конца»

Полная система знакомств в одном Telegram-боте: пользователь проходит весь путь —
**вход → язык → правила 18+ → анкета → поиск → взаимный лайк → анонимный диалог →
выход (удаление данных)** — с защитой на каждом этапе.

Python 3.11 · aiogram 3 · SQLite · AES-256-GCM.

## Чем отличается от обычного бота знакомств

| Этап | Что происходит | Защита |
|---|---|---|
| Вход | Выбор языка, правила, подтверждение 18+ | Анкета создаётся только после согласия |
| Анкета | Имя, возраст, город, о себе, интересы, фото | Жёсткая валидация, поля **шифруются AES-256-GCM** — в базе нет открытых данных |
| Поиск | Лента анкет, ❤️ / ➡️ / 🚩 | Не показываются забаненные, скрытые и заблокированные; лайкать можно только со своей анкетой |
| Мэтч | Взаимный лайк → уведомление обоим | Telegram ID сторон **не раскрываются** друг другу |
| Общение | Анонимный диалог через бота (текст и фото) | Сообщения **нигде не хранятся**, лимит 20/мин, кнопки «завершить / заблокировать / пожаловаться» |
| Выход | Скрыть анкету или удалить все данные | Полное удаление анкеты, лайков, диалогов и пользователя |

## Слой безопасности

- 🔐 **Шифрование анкет в базе** (AES-256-GCM, ключ выводится из `MASTER_KEY`
  через PBKDF2-HMAC-SHA256, 200 000 итераций). Кража файла базы не даёт имён,
  городов, описаний и фото.
- 🧹 **Нулевое хранение переписки**: сообщения диалогов пересылаются напрямую,
  в базе нет даже таблицы для них.
- 🛡 **Анти-флуд**: 25 сообщений/мин и 20 нажатий/мин на пользователя;
  3 нарушения за 10 минут → мут 5 минут (пишется в базу, переживает перезапуск).
- 🔒 **Анонимность**: собеседники общаются через бота, Telegram ID скрыты.
- 🚩 **Жалобы**: 5 новых жалоб → автобан нарушителя; админ получает уведомление
  с кнопками «забанить / отклонить».
- 🧾 **Аудит админ-действий**: баны, удаления, репутация — всё в журнал `audit`.
- 🧨 **Право на забвение**: кнопка «Удалить мои данные» стирает всё.
- 🇷🇺🇬🇧 Двуязычный интерфейс (ru/en).
- Параметризованные SQL-запросы (нет SQL-инъекций), экранирование HTML во всех
  пользовательских данных (нет HTML-инъекций), проверка длины и управляющих
  символов в каждом поле.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# 1) Впиши новый токен из @BotFather (старый отзови через /revoke!)
# 2) Сгенерируй мастер-ключ и впиши в MASTER_KEY:
python -c "import secrets; print(secrets.token_urlsafe(32))"

python bot.py
```

Проверить систему без запуска бота можно тестами:

```bash
python tests/test_core.py   # шифрование, лимиты, БД, миграции, автобан
python tests/test_flow.py   # полный путь пользователя «от входа до конца»
```

## Структура проекта

```
bot.py                  # точка входа
app/
  config.py             # конфигурация из .env + валидация при старте
  security.py           # AES-256-GCM, RateLimiter, MuteTracker, валидация
  db.py                 # SQLite: схема, миграции, параметризованные запросы
  i18n.py               # строки ru/en
  keyboards.py          # клавиатуры и метки кнопок
  middlewares.py        # глобальный анти-флуд
  handlers/
    onboarding.py       # /start, язык, правила, /help, выход в меню
    profile.py          # мастер анкеты с валидацией
    browse.py           # лента, лайки, мэтчи, жалобы
    chat.py             # анонимные диалоги (пересылка без хранения)
    settings.py         # язык, видимость, удаление данных
    admin.py            # админ-панель, очередь жалоб, аудит
tests/                  # тесты ядра и полного пути пользователя
```

## Меню пользователя

- 🔎 **Смотреть** — лента анкет (❤️ нравится / ➡️ дальше / 🚩 жалоба)
- 💬 **Диалоги** — список мэтчей, вход в анонимный чат
- 📝 **Моя анкета** — просмотр, изменение, удаление
- ⚙️ **Настройки** — язык, скрыть/показать анкету, удалить все данные

## Админ-панель

Команда `/admin` (доступ только у `ADMIN_ID` из `.env`):

- 📊 Статистика — пользователи, анкеты, мэтчи, жалобы, баны
- 🚩 Жалобы — очередь новых с кнопками «забанить / отклонить»
- 🔍 Найти анкету — по ID анкеты или Telegram ID
- 🗑 Удалить по ID, ⛔ Бан, ✅ Разбан, ⭐ Репутация (+1 / -2)
- 🧾 Аудит — последние 10 действий администраторов

Каждое действие пишется в журнал аудита.

## Важно про токен (ещё раз)

Токен предыдущей версии бота был опубликован в переписке — **отзови его в
BotFather командой `/revoke`**, создай новый и запиши только в `.env`.
Файл `.env` в `.gitignore`.

## Честное предупреждение

Абсолютно незламываемых систем не существует. Здесь применён стандартный набор
серьёзных мер: шифрование данных покоя, отсутствие хранения переписки,
rate limiting, автобаны, аудит и принцип минимальных данных. Для продакшена
дополнительно: запуск от отдельного пользователя без root, firewall, бэкапы,
webhook за reverse proxy с HTTPS, мониторинг и регулярная смена `MASTER_KEY`
(старый ключ не восстанавливает данные после смены — храни его в менеджере
секретов).
