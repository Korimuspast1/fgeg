# PZ3D — автоустановщик для Project Zomboid (Build 42)

Один запуск `start.bat` — и всё ставится само: скачивается мод **pz3d**,
скачивается и устанавливается **ZombieBuddy** (Java-загрузчик, без него pz3d
не работает), файлы раскладываются по нужным папкам, лаунчер игры патчится,
моды включаются автоматически.

## Что требуется

- Windows 10/11 (x64).
- **Project Zomboid Build 42.21.0** — на других версиях pz3d не запустится.
- Интернет при первой установке (качается ~25 МБ с GitHub).
- Рекомендуется 8+ ГБ ОЗУ (установщик сам выставит игре минимум 4 ГБ).

## Установка

1. Скачайте файлы из этого репозитория — достаточно **`start.bat`** и
   **`install.ps1`** в одной папке (весь репозиторий качать не обязательно:
   Code → Download ZIP → распаковать).
2. **Запустите `start.bat`** двойным кликом.
3. Если установщик не нашёл игру сам — вставьте путь к папке, где лежит
   `ProjectZomboid64.exe` (например `C:\Games\Project Zomboid`).
   Папку можно просто **перетащить мышкой на start.bat** — тогда вопросов
   не будет вообще.
4. Дождитесь надписи «ГОТОВО» и запустите игру.

Если игра стоит в `Program Files` и нужны права администратора — установщик
сам перезапустится от имени администратора.

## После запуска игры

1. При **первом** запуске ZombieBuddy покажет окно подтверждения Java-мода
   pz3d (там указан путь к JAR и его хеш) — нажмите **Yes**, выбор можно
   запомнить.
2. В главном меню в строке версии игры должна появиться приписка `[ZB]` —
   значит загрузчик работает.
3. Создайте **новое одиночное** сохранение (мультиплеер pz3d не поддерживает).
4. После появления в мире нажмите **Insert** — вход в 3D-режим.

## Что именно делает установщик

| Действие | Куда |
|---|---|
| Мод `pz3d` + пример `pz3d_chainlink` | `%USERPROFILE%\Zomboid\mods\` |
| Мод `ZombieBuddy` (+ `libs\ZombieBuddy.jar`, `zbNative.dll`) | `%USERPROFILE%\Zomboid\mods\ZombieBuddy\` |
| `ZombieBuddy.jar`, `zbNative.dll` | в папку игры (рядом с `ProjectZomboid64.exe`) |
| `-agentlib:zbNative` + `-Xmx` ≥ 4096m | `ProjectZomboid64.json` |
| `SET _JAVA_OPTIONS=-agentlib:zbNative` | `ProjectZomboid64.bat` (если есть) |
| Включает `ZombieBuddy`, `pz3d`, `pz3d_chainlink` | `Zomboid\mods\default.txt` |

Все изменяемые файлы сначала копируются в `*.bak.<дата-время>` рядом с собой —
откат всегда возможен. Остальные моды отключаются намеренно: pz3d требует
чистую игру только с ZombieBuddy.

## Если что-то пошло не так

- **«Не удалось скачать»** — нет интернета или GitHub заблокирован на ПК.
  Положите `3807334881_pz3d.zip` из репозитория рядом со `start.bat` — мод
  возьмётся локально (ZombieBuddy всё равно качается с GitHub).
- **SmartScreen/антивирус ругается** — «Подробнее → Выполнить в любом случае».
  Скрипт открыт: весь код в `install.ps1`, ничего скрытого нет.
- **Ошибка про версию при запуске мода** — игра не 42.21.0. Обновите игру.
- **Нет 3D** — подождите полной загрузки мира и нажмите `Insert`; проверьте,
  что в строке версии есть `[ZB]`, а моды включены (Меню → Моды).
- **Логи игры** — `%USERPROFILE%\Zomboid\console.txt`.
- **Удалить всё** — запустите: `powershell -ExecutionPolicy Bypass -File install.ps1 -Uninstall`.

## Файлы

| Файл | Назначение |
|---|---|
| `start.bat` | Запуск установщика (это и есть «одна кнопка»). |
| `install.ps1` | Вся логика установки/удаления. |
| `3807334881_pz3d.zip` | Исходник мода pz3d (воркшоп 3807334881). Установщик скачает его сам; если лежит рядом — использует локально. |

> Почему не `start.exe`: голый `.exe`, собранный неизвестно где, антивирусы
> режут почти всегда, а `.bat` + `.ps1` — это те же «два клика», только
> прозрачно и без блокировок. Если очень хочется exe — `start.bat` можно
> обернуть любым bat2exe, логика от этого не меняется.
