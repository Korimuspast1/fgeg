# Безопасность

1. Токен бота нельзя публиковать в чате, GitHub, логах или коде. Отзови опубликованный токен через BotFather и создай новый.
2. Новый токен записывай только в `.env`; файл уже добавлен в `.gitignore`.
3. Для продакшена запускай процесс от отдельного пользователя без root, включи firewall и резервное копирование SQLite.
4. Для GitHub используй только GitHub Actions Secrets, например `BOT_TOKEN`, а не обычные переменные в workflow.
5. Админ ID зафиксирован в `.env`; доступ к админке проверяется по Telegram ID. Никому не передавай доступ к аккаунту Telegram администратора.
6. Перед публичным запуском добавь rate limit, модерацию фото, ограничение размера полей, жалобы с очередью и webhook за reverse proxy с HTTPS.
7. После любого подозрительного доступа отзови токен в BotFather.
